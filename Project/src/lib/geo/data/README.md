# Spain boundaries

Source: https://github.com/codeforgermany/click_that_hood/blob/main/public/data/spain-provinces.geojson

Province boundaries are simplified for game rendering. Community boundaries are unions of their member provinces. GeoJSON rings use D3's clockwise exterior convention.

Province mode contains Spain's 50 provinces; community mode contains its 17 autonomous communities. Ceuta and Melilla are autonomous cities, not provinces or autonomous communities, and are excluded from these two modes.
